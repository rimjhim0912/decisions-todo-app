# Todo Application

A full-stack Todo application built using C#, ASP.NET Core Web API, React, and Microsoft SQL Server. It helps users manage daily tasks, organize them by category, and track their completion status.

## Features
- Add, edit, delete, and view tasks
- Search tasks by title or description
- Filter tasks by category and priority
- Mark tasks as completed
- Validate inputs and handle errors

## Tech Stack
- **Backend:** C#, ASP.NET Core Web API
- **Frontend:** React, JavaScript, CSS
- **Database:** Microsoft SQL Server, Entity Framework Core

## How to Run

**Backend**
```bash
dotnet restore
dotnet build
dotnet run
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

Make sure SQL Server is configured and the database connection string is set before starting the backend.

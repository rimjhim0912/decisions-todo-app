\# Todo Application



A simple full-stack application for managing daily tasks, built with C#, ASP.NET Core Web API, React, and Microsoft SQL Server.



\## Features

\- Create, edit, delete, and view tasks

\- Search tasks by title or description

\- Filter tasks by category and priority

\- Mark tasks as completed

\- Input validation and error handling



\## Tech Stack

\- \*\*Backend:\*\* C#, ASP.NET Core Web API

\- \*\*Frontend:\*\* React, JavaScript, CSS

\- \*\*Database:\*\* Microsoft SQL Server, Entity Framework Core



\## How to Run



\*\*Backend\*\*

```bash

dotnet restore

dotnet build

dotnet run

```



\*\*Frontend\*\*

```bash

cd frontend

npm install

npm run dev

```



Configure the SQL Server connection string before running the backend.
